<h2>LANCER LE SITE EN LOCAL</h2>
<p>Pour ouvrir correctement le site, suivre les étapes suivantes :</p>

<h3>1- Ouvrir le projet</h3>
    <p>Ouvrir le dossier complet du projet avec Visual Studio Code</p>

<h3>2- Démarrer le serveur</h3>
    <p>Ouvrir le terminal intégré</p>
    <p>Exécuter la commande suivante :</p>
  <p>python serveur.py</p>
    <p>ou :</p>
  <p>py serveur.py</p>
    
<h3>3- Accéder au site</h3>
    <p>Ouvrir un navigateur web</p>
    <p>Aller à l’adresse suivante :</p>
  <p>http://localhost:8000</p>

<h2>REMARQUE</h2>
<p>Vérifier que Python est bien installé sur votre machine</p>
<p>S’assurer que le port 8000 n’est pas déjà utilisé</p>
