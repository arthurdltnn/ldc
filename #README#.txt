Lancer le site en local

Pour ouvrir correctement le site, suivre les étapes suivantes :


1. Ouvrir le projet

Ouvrir le dossier complet du projet avec Visual Studio Code


2. Démarrer le serveur

Ouvrir le terminal intégré

Exécuter la commande suivante :

	python serveur.py

ou (selon la configuration) :

	py serveur.py


3. Accéder au site

Ouvrir un navigateur web

Aller à l’adresse suivante :

	http://localhost:8000


Remarque : 

Vérifier que Python est bien installé sur votre machine

S’assurer que le port 8000 n’est pas déjà utilisé
